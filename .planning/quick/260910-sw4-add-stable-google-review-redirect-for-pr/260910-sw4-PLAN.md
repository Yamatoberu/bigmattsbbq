| public internet -> Next.js routing layer | Anonymous GET on `/review`; no request body, no auth, no session |
| Next.js -> third-party (google.com / g.page) | Outbound destination the user's browser follows after the 307 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-sw4-01 | Tampering | `next.config.js` redirects() | mitigate | Destination is a hardcoded literal with no interpolation of `source` params, query string, or headers — structurally cannot become an open redirect |
| T-sw4-02 | Information disclosure | `/review` request | accept | Route is anonymous and static; it reads no session, cookie, Square, or Supabase data and returns no body |
| T-sw4-03 | Spoofing | g.page destination | transfer | Destination is Google-operated; correctness of the review form is Google's responsibility. A wrong-but-valid destination is caught by the Task 1 exact-string assertion and the post-deploy human check |
| T-sw4-SC | Tampering | package installs | accept | No new npm/pip/cargo dependencies are added by this plan — package legitimacy gate does not apply |
