<objective>
Ship the pure data-shaping layer behind all three Analytics trend requirements: one shared `buildTrendSeries(cooks, metric)` function that converts `CookWithScore[]` (already ascending by `cooked_at`) into a chronological `TrendPoint[]` for any of seven metrics, with null-safety baked in.

Purpose: All 7 chart instances on `/sca/analytics` (ANLY-01 total score, ANLY-02 gap-to-first, ANLY-03 five categories) read from this one function — no duplicated metric-selection or gap math anywhere (D-01, INFRA-05).
Output: `lib/sca/trends.ts` (new, named exports only) and `tests/sca-trends.test.ts` (new, Wave 0 gate for ANLY-01/02/03).
</objective>
