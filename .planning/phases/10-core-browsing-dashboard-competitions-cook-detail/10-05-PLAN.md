Props: `{ model: ComparisonTableModel; caption?: string }`.

Behavior:
- If `model.columns.length === 0`, render a single `.glass-card p-6` block with `text-sm text-smoke-800` copy "No cooks recorded yet." and nothing else.
- Otherwise render a `.glass-card` wrapper containing a `<div className="overflow-x-auto">` around a `<table className="w-full min-w-max border-collapse text-sm">`. The `overflow-x-auto` container is D-03's locked mobile strategy — do not add a stacked/card-per-cook responsive variant and do not use `overflow-hidden` on any ancestor inside this component.
- `<caption>` renders the `caption` prop when provided, styled `sr-only` (the visible section heading lives on the page).
- `<thead>`: first cell is an empty `<th scope="col">` for the row-label gutter; then one `<th scope="col">` per `model.columns`. Header cell classes: `px-3 py-2 text-left text-xs font-semibold uppercase tracking-[0.25em] whitespace-nowrap`. When a column has a non-null `href`, wrap its label in a `next/link` `<Link>` with the ScaNavBar link classes (`hover:text-gold-300`, `focus-visible:outline ... outline-ember-500`) and `min-h-[44px] inline-flex items-center` so the tap target meets the UI-SPEC minimum.
- Best-column accent: a column with `kind === "best"` gets `text-gold-300` on its header and a subtle left border (`border-l border-ember-500/40`) on its header and every body cell in that column. This is the single accent callout and the Competition Detail focal point — no other column receives accent color. The `worst` and `average` columns use the default `text-smoke-800` header treatment.
- `<tbody>`: one `<tr>` per `model.rows`. First cell is `<th scope="row" className="px-3 py-2 text-left text-xs font-semibold uppercase tracking-[0.25em] text-smoke-800 whitespace-nowrap">{row.label}</th>`, then one `<td className="px-3 py-2 text-sm text-[#f7f1e6] whitespace-nowrap">` per cell, rendered by index so `row.cells[i]` aligns with `model.columns[i]`. Add a row separator via `border-t border-[#3a2a20]` on `<tr>`.
- Render `row.cells[i]` verbatim as JSX text. Do NOT null-check, reformat, substitute a placeholder, or call any `lib/sca/format` function — the model already contains the em dash where a value is missing (D-04). Do NOT use `dangerouslySetInnerHTML`.
- No new colors, fonts, sizes, or CSS classes beyond the tokens listed in the UI contract above.
