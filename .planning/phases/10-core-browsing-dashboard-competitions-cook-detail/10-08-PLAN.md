<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public visitor → `/sca/cooks/[id]` path segment | Attacker-controlled string reaching server-side code |
| AI-generated review text → rendered page | `cook_ai_review.comments` / `prompt` are model-authored free text — the least controlled string source on the entire site |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-26 | Tampering | `[id]` route param | mitigate | `parseScaId(id)` before any query; `null` → `notFound()`. Unit-tested in Plan 10-04, asserted here by the two `curl` 404 checks. (ASVS V5.) |
| T-10-27 | Tampering (stored XSS) | `cook_ai_review.comments` / `prompt`, `cook_detail` note fields | mitigate | Rendered as JSX text with `whitespace-pre-line` for line breaks — never `dangerouslySetInnerHTML` and never a markdown/HTML renderer. React escapes the content, so injected markup displays as literal text. Gated by `grep -c "dangerouslySetInnerHTML" == 0`. |
| T-10-28 | Information Disclosure | catch block | mitigate | `logError()` server-side; visitor sees the locked generic string only. Gated by `grep -c "error.message" == 0`. |
| T-10-29 | Information Disclosure (IDOR) | `/sca/cooks/[id]` | accept | All cook rows are public competition history for a single chef; no auth, no ownership boundary, no PII in the `sca` schema this milestone. Enumeration exposes nothing beyond the Dashboard's own all-cooks table. Revisit at PLAT-01 (multi-chef). |
| T-10-30 | Denial of Service | cook with `score: null` (real cook 7) | mitigate | The whole `cook.score` object is null-guarded before any field access, and both distance values route through `deriveScoreMetrics`, which accepts nulls — so the sparse-data path renders em dashes instead of throwing during SSR |
| T-10-SC | Tampering | npm installs | accept | No package-manager installs in this phase (RESEARCH.md Package Legitimacy Audit: not applicable) |
