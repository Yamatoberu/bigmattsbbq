## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-06 | Tampering (stored XSS) | `buildComparisonTable` cell strings, `getPresentProcessFields` values | mitigate | Both functions emit plain JavaScript strings only — no HTML fragments, no template-built markup. The Wave 3 rendering components interpolate them as JSX text, which React escapes. `dangerouslySetInnerHTML` is prohibited in every Phase 10 file. |
| T-10-07 | Denial of Service | `buildComparisonTable` with an empty or all-unscored cook set | mitigate | Aggregate columns are sourced from `computeBestWorstAverage`/`computeCategoryAverages`, which return nulls for empty sets; `formatScoreValue` converts null to the em dash, so no path divides by zero or dereferences a null cook |
| T-10-08 | Information Disclosure | process-variable field list | accept | Only competition process data is exposed; `id`/`cook_id`/timestamps are excluded from display by construction |
| T-10-SC | Tampering | npm installs | accept | No package-manager installs in this phase (RESEARCH.md Package Legitimacy Audit: not applicable) |
</threat_model>
