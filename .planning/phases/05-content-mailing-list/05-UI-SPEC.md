## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding (`gap-1`, `px-1`) |
| sm | 8px | Compact element spacing (`gap-2`, `px-2`) |
| md | 16px | Default element spacing (`gap-4`, `px-4`) |
| lg | 24px | Section padding (`py-6`, `gap-6`) |
| xl | 32px | Layout gaps (`gap-8`, `mt-8`) |
| 2xl | 48px | Major section breaks (`py-12`) |
| 3xl | 64px | Page-level spacing (`py-16`) |

Exceptions:

- Nav touch targets (hamburger button, cart button): minimum 44px × 44px hit area — use `min-h-[44px] min-w-[44px]` on the interactive element.
- Logo in NavBar: 125px × 125px fixed — matches existing `h-[125px] w-[125px]`.
- Footer mailing list row: single line `flex` layout; no vertical rhythm exception needed.

## Interaction Contract

### Mailing list form (home section + footer)

1. User enters email and submits.
2. Button enters disabled + loading state: label changes to "…" (`disabled` + `cursor-not-allowed`).
3. `POST /api/mailing-list` — body `{ email: string }`.
4. On 200 or 409 (already subscribed): replace form with success message (D-07, D-08).
5. On 4xx/5xx: show error copy inline below form. Input remains editable. Button re-enables.
6. No page navigation on any outcome.

### Mobile nav drawer

1. Tap hamburger: drawer slides in from left (`translate-x-0`), overlay appears.
2. Tap any nav link: drawer closes (`-translate-x-full`), overlay disappears.
3. Tap overlay: drawer closes.
4. Press `Escape`: drawer closes.
5. Cart badge remains visible in header at all times — never hidden by open drawer.
6. `aria-expanded` on hamburger button reflects open state.
7. `aria-label="Open navigation menu"` / `"Close navigation menu"` toggles on hamburger.

### Unsubscribe page

1. On mount: read `?token=` query param.
2. If no token: immediately show invalid state.
3. If token present: show loading state, call `POST /api/unsubscribe` with `{ token }`.
4. On success: show success state.
5. On error (invalid/expired): show invalid state.
6. No retry mechanism — the expired-link copy directs user to their most recent email.

### Focus management

- All interactive elements use `focus-visible:outline focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-ember-500` — already in `.button-primary` and `.button-secondary` global classes. Apply same pattern to nav links and input fields.
- Drawer open: move focus to first nav link inside drawer.
- Drawer close: return focus to hamburger button.
