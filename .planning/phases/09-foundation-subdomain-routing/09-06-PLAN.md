<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Server Component -> browser HTML | Data read with the service-role key is serialized into public HTML here |
| server-only module -> client component | The `sca` client must never be pulled across this boundary |
| Supabase error -> rendered page | Error text from the database can reach the user's screen |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-61 | Information Disclosure | app/sca/page.tsx | mitigate | The page is a Server Component with no `"use client"` directive; `lib/supabase-sca.ts` carries `import "server-only"`, so any accidental client import fails `npm run build`. Enforced by a grep plus build acceptance criterion. |
| T-09-62 | Information Disclosure | rendered error state | mitigate | Only the Supabase `error.message` is rendered — never the client instance, the connection URL, or the service-role key. The page selects `count` only with `head: true`, so no row data is transferred or serialized. |
| T-09-63 | Information Disclosure | over-fetching | mitigate | `select("*", { count: "exact", head: true })` returns a count with zero rows in the payload, so the service-role client cannot leak `sca` row contents through this page even though it has RLS-bypassing access. |
| T-09-64 | Tampering | user input in queries | mitigate | This page accepts no route params, search params, or form input. The query is fully static, so there is no injection surface. Phase 10 must keep any future filters on the supabase-js query builder rather than raw SQL. |
| T-09-65 | Spoofing | logo link target | mitigate | The back-to-marketing-site link uses the absolute literal `https://bigmattsbbq.com` with `rel="noopener"`, hardcoded rather than derived from a request header, so it cannot be redirected by a forged Host. |
| T-09-SC | Tampering | npm/pip/cargo installs | mitigate | Not applicable — no packages installed. All imports (`next/image`, `next/link`, `next/navigation`, `@supabase/supabase-js`) are pre-existing dependencies. |
</threat_model>
