## New UI Element: Mailing List Opt-In Checkbox

This is the only new visual element in Phase 4.

### Placement

Inside the `<form>` in `CheckoutClient.tsx`, below the email/phone grid and above the error message and submit button. Immediately after the `grid gap-4 md:grid-cols-2` div closes.

### Visual Spec

```
[  ] Notify me about future drops
```

- Container: `flex items-center gap-2 mt-4`
- Checkbox: native `<input type="checkbox">` with `rounded` and `accent-ember-500` (or `accent-[#e64622]`) to match ember color scheme
- Label text: "Notify me about future drops"
- Label size: `text-sm` (14px), weight 400, color `text-smoke-600`
- Default state: unchecked
- No required indicator — opt-in is always optional (D-06)

### Interaction States

| State | Appearance |
|-------|-----------|
| Unchecked (default) | Empty checkbox, label at `text-smoke-600` |
| Checked | Filled checkbox with ember accent color, label unchanged |
| Disabled | Not applicable — checkbox is always enabled during form interaction |

### Accessibility

- Wrap checkbox and label in `<label>` element so the entire row is clickable
- `htmlFor` / `id` pairing not required when input is a direct child of the label
- Use `aria-describedby` only if a helper sub-text is added (not required by current spec)

### Implementation reference

```tsx
<label className="flex cursor-pointer items-center gap-2 mt-4">
  <input
    type="checkbox"
    checked={optInMailingList}
    onChange={(e) => setOptInMailingList(e.target.checked)}
    className="h-4 w-4 rounded accent-[#e64622]"
  />
  <span className="text-sm text-smoke-600">Notify me about future drops</span>
</label>
```

State: `const [optInMailingList, setOptInMailingList] = useState(false);`
