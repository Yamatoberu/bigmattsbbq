<objective>
Fix Issue 3 from `public/code_review.md` — nested `<main>` regression.

`app/layout.tsx` currently wraps `{children}` in `<main>`, while three pages
(`app/checkout/page.tsx`, `app/confirmation/page.tsx`, `app/orders/page.tsx`) also
render their own root `<main>`. HTML5 allows only one `<main>` per document. The
UI review previously logged this as fixed, but the layout was reverted to `<main>`
at some point — this plan restores Option A from the code review (layout uses
`<div id="page-content">`, pages keep their own `<main>`).

Purpose: Eliminate invalid nested `<main>` markup; restore valid HTML5 landmarks.
Output: `app/layout.tsx` updated; the three page files reviewed and confirmed
unchanged (they're already correct under Option A).
</objective>
