<objective>
Add a server-side precheck to `/api/checkout` that rejects orders when the drop is inactive or globally sold out (ORD-04), swap the Zod schema from the old `pickup: { locationLabel: enum }` shape to the new `{ dropId, pickupOptionId }` shape, and lock the behavior with unit tests. This plan does NOT touch `components/CheckoutClient.tsx` — plan 05 updates the client payload to match the new schema. Between this plan and plan 05, `CheckoutClient` will still send the old shape and checkout will 400, but the route itself is the contract and must be updated first so plan 05 can build to a stable target.

Purpose: Satisfies ORD-04 (checkout validates drop is active before accepting orders). The existing `reserve_pickup_slot` RPC checks capacity but NOT `drops.status`, so a closed-but-empty drop would currently accept orders. This plan closes that gap with an explicit precheck. It also swaps the schema so the storefront can send a real `dropId` FK instead of hand-typed location enums.

Output:
- `lib/drops.ts` — adds pure helper `checkDropReady(row)` returning a discriminated union
- `app/api/checkout/route.ts` — new Zod schema, Supabase drop precheck, `checkDropReady` call before any Square API calls, reads `pickup_at` and `location_label` from the `drop_pickup_options` row for the Square order fulfillment
- `tests/checkoutDropGate.test.ts` — 6+ unit tests for `checkDropReady`
- `npx vitest run tests/checkoutDropGate.test.ts` exits 0; full suite still green
</objective>

    export interface DropReadinessRow {
      status: string;
      capacity_pulled_pork: number;
      capacity_brisket: number;
      reserved_pulled_pork: number;
      reserved_brisket: number;
    }

    export type DropReadiness =
      | { ok: true }
      | { ok: false; status: number; error: string };

    export function checkDropReady(drop: DropReadinessRow | null): DropReadiness {
      if (!drop) {
        return { ok: false, status: 404, error: "Drop not found." };
      }
      if (drop.status !== "active") {
        return {
          ok: false,
          status: 409,
          error: "This drop has closed. Orders are no longer being accepted."
        };
      }
      const globallySoldOut =
        drop.reserved_pulled_pork >= drop.capacity_pulled_pork &&
        drop.reserved_brisket >= drop.capacity_brisket;
      if (globallySoldOut) {
        return {
          ok: false,
          status: 409,
          error: "This drop has sold out. No more orders can be taken."
        };
      }
      return { ok: true };
    }
