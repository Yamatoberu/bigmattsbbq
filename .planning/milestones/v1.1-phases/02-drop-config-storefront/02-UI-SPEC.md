## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline list bullet padding |
| sm | 8px | Compact element spacing, badge internal padding |
| md | 16px | Default element spacing (card padding inner gaps) |
| lg | 24px | Section padding, card padding (`p-6`) |
| xl | 32px | Layout gaps between grid rows |
| 2xl | 48px | Major section breaks (`.section-spacing` `py-12`) |
| 3xl | 64px | Page-level hero vertical padding |

Exceptions:
- Touch targets for pickup option cards: minimum 44px tall (mobile tap target standard)
- `.section-spacing` uses `py-12 px-6 md:py-12 md:px-12` — follows existing convention exactly

Source: `app/globals.css` `.section-spacing`, `components/PackageCard.tsx` `p-6`, default; no changes to existing scale.

## New Components: Visual Contracts

### Teaser Page (no active drop / closed drop)

Renders instead of the ordering flow when `drop.state !== 'active'`.

**Layout:** Full-page centered panel. Reuses `.hero-panel` + `.hero-content` classes from existing OrderLanding hero. NavBar and Footer unchanged.

**Elements:**
- Big Matt's BBQ logo/wordmark (existing asset at top)
- Display headline (Playfair Display, 36px mobile / 48px desktop, semibold): "Next Drop Coming Soon"
- Body copy (16px, regular, `text-smoke-700`): "Join the list and we'll notify you the moment a new drop opens."
- Mailing list email input + CTA button (Phase 4 will wire the backend; Phase 2 renders the input as a static capture stub with a success toast placeholder)
- CTA label: "Notify Me"
- Footer: unchanged

**Background:** Inherits `bg-ember-radial bg-grain` from `<main>` — same as active ordering page.

### Drop Header Banner

Renders inside OrderLanding when drop is active. Replaces the hardcoded `"Orders close March 10, 2026."` line.

**Position:** Below the hero CTAs, same `<p>` slot with `text-xs uppercase tracking-[0.35em] text-[#d9c7b3]`.

**Content pattern:** `{drop.title} — Orders close {formattedCutoff}` (e.g. "April 2026 Drop — Orders close Apr 30, 2026 at 11:59 PM")

**No banner box or colored highlight** — plain text, same styling as existing hardcoded line. Source: `components/OrderLanding.tsx` line 76.

### Pickup Option Cards (rendered in CheckoutClient)

Cards are selectable; customer picks one pickup location during checkout. Follows PackageCard visual pattern but simpler.

**Structure:**
```
[glass-card] rounded-lg border border-[#3a2a20] bg-[#16100c] p-5
  Location name     — text-base font-semibold text-smoke-900, Playfair Display
  Date              — text-sm text-smoke-700, Source Sans 3
  Time window       — text-sm text-smoke-600, Source Sans 3
  [selected state]  — border-[#d8b56a] ring-1 ring-[#d8b56a]/40 (gold ring)
  [sold-out state]  — opacity-60, pointer-events-none, "Sold Out" badge overlay
```

**Interaction:**
- Default: `border-[#3a2a20]`
- Hover (not sold-out): `hover:border-[#b8893a]` (matches button-secondary hover)
- Selected: `border-[#d8b56a] ring-1 ring-[#d8b56a]/40`
- Sold-out: `opacity-60 cursor-not-allowed` + `.badge` "Sold Out" with `bg-smoke-300 text-smoke-50` (grey badge, not gold)
- Minimum height: 72px to meet 44px touch target on mobile

**Grid:** `grid gap-4 md:grid-cols-2` — two columns on desktop, single on mobile.

Source: `02-CONTEXT.md` D-05, D-06; `components/PackageCard.tsx` visual pattern.

### Sold-Out Product Cards (FrozenItemCard modification)

When `drop.state === 'active'` but global capacity is exhausted (ORD-05), all FrozenItemCards display a sold-out state.

**Treatment:**
- Card wrapper: `opacity-60` applied to the article element
- Variation row button: already uses `disabled:bg-smoke-300 disabled:text-smoke-600` — no change needed
- Button label changes from "Add to Cart" to "Sold Out" (already conditional in FrozenItemCard line 38)
- No badge overlay on the card — the disabled button text is sufficient

Source: `02-CONTEXT.md` D-08; `components/FrozenItemCard.tsx`

### Loading Skeleton

Replaces the plain `"Loading frozen menu..."` text. Applied while `useActiveDrop` and `useFrozenItems` resolve.

**Treatment:** Three placeholder cards in the package grid and three in the frozen items grid.

```
[glass-card] p-6 animate-pulse
  [div] h-5 w-1/2 rounded bg-smoke-300/30 mb-3   — title placeholder
  [div] h-3 w-3/4 rounded bg-smoke-300/20 mb-2   — body line 1
  [div] h-3 w-1/2 rounded bg-smoke-300/20         — body line 2
```

Tailwind's `animate-pulse` provides the shimmer. Color: `bg-smoke-300/30` and `bg-smoke-300/20` — matches the dark surface without harsh contrast.

Source: Claude's Discretion (02-CONTEXT.md); defaulting to standard pulse skeleton pattern.

### Error Banner

Reuses the existing error pattern from OrderLanding:

```
glass-card border border-ember-400 bg-[#1a120e] p-4 text-sm text-ember-200
  [error message text]
  [button.button-secondary ml-3 text-xs] "Retry"
```

Applied to both drop-fetch errors and frozen-items errors.

Source: `components/OrderLanding.tsx` lines 121–126.

## Interaction States

| State | Visual Treatment |
|-------|-----------------|
| Drop active | Full ordering page with Drop Header Banner; add-to-cart enabled |
| Drop inactive / closed | Teaser page; ordering page hidden entirely |
| Product sold out (global capacity) | FrozenItemCard `opacity-60`; button disabled "Sold Out" |
| Pickup location sold out | PickupOptionCard `opacity-60 cursor-not-allowed` + grey "Sold Out" badge |
| Pickup location selected | `border-[#d8b56a] ring-1 ring-[#d8b56a]/40` gold ring |
| Data loading | Pulse skeleton cards (3 in each grid section) |
| Fetch error | Ember-tinted error banner + Retry button |
| Drop cutoff passed (server-side) | 400 response from checkout; client shows inline error "This drop has closed." |
