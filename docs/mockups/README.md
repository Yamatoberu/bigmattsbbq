## Source of truth

Images are conceptual, not functional UI, and may contain illustrative dates, counts, prices, statuses, and labels. Use the feature issues, current catering configuration, existing database models, real order/payment status, and business rules for implementation. Do not implement mocked pricing, quantities, stock/capacity constraints, or event dates as authoritative requirements. Responsive screens should be implemented as accessible components and tested at small and large viewport widths.
